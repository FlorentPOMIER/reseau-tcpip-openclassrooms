# Réseau TCP/IP – projet OpenClassrooms

Projet réalisé dans le cadre du parcours OpenClassrooms « Concevoir un réseau TCP/IP » (2026).

## Objectif
Concevoir l'architecture physique du réseau + configuration + Ajout de DHCP et DNS

## Ce que j'ai réalisé
- Plan d'adressage IP : sous-réseaux, masques, passerelles
  Configuration de DNS / DHCP / routage / switching
- Tests de connectivité : ping, traceroute

## Outils
Cisco Packet Tracer
